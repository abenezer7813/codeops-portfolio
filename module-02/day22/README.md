# Birr Watch

Birr Watch is a simple JavaScript currency converter and exchange-rate watchlist.

## What It Does

* Shows the current exchange-rate status.
* Allows the user to enter an amount.
* Allows the user to select a currency.
* Converts the amount into the selected currency.
* Displays the conversion result.
* Shows currencies in a watchlist.
